WH Digital – Meine Aufgaben / GitHub Pages

1. Bei github.com anmelden und ein neues PUBLIC Repository erstellen, z.B. wh-digital-aufgaben.
2. Unter Add file > Upload files die Dateien index.html, sw.js, manifest.webmanifest, icon.svg, icon-192.png, icon-512.png hochladen. Nicht den übergeordneten Ordner hochladen.
3. Commit changes anklicken.
4. Settings > Pages > Build and deployment: Source = Deploy from a branch; Branch = main; Folder = /(root); Save.
5. Nach Bereitstellung die angezeigte Pages-Adresse auf Android in Chrome öffnen.
6. Chrome-Menü > App installieren oder Zum Startbildschirm hinzufügen.

Wichtig: Repository und Programmcode sind öffentlich; keine privaten Daten dort hochladen. Aufgaben und Fotos liegen nur lokal in IndexedDB des Android-Browsers. Regelmäßig die Sicherung aus der App exportieren. Löschen von Browser-/App-Daten kann alle Aufgaben entfernen. Spracherkennung kann Online-Dienste verwenden. GitHub Pages ist HTTPS; PWA funktioniert nach Erstaufruf offline, soweit Dateien gecacht sind.
